# Exploring Gen UI
Imagine you could create UI's on the fly! <br>
Imagine your experience was bespoke! <br>
Imagine you could filter out the fluff and get to where you want!

## Package overview

### client
- Vite
- React
- Typescript
- Tailwind

### server
- Node.js (tsx-node)
- Express.js
- Zod

### ai framework
- Vercel's AI SDK
- [AI-SDK-Ollama]( https://github.com/jagreehal/ai-sdk-ollama)'

### LLM host
- Ollama for local model management

### LLM
- Currently Qwen2.5 or Qwen3
